# 🕵️‍♂️ Insight Search: Анализ комментариев Instagram

Учебный проект (ГрГУ им. Я. Купалы, группа «Искусственный интеллект»).
Приложение анализирует комментарии к постам из Instagram: определяет тональность, группирует по темам, ищет инсайты и выгружает готовые отчёты.

*Автор: Потапчик Анастасия*

## 🚀 Функционал
- **Загрузка данных**: поддержка CSV, Excel, JSON. В комплекте идет тестовый датасет `real_comments_labeled.csv` с реальными комментариями.
- **Поиск**: по ключевым словам, по ссылке на пост, по автору или по одному тексту.
- **Тональность**: определение негатива, позитива и нейтрала с помощью ML-модели RuBERT и гибридных словарей.
- **Темы и кластеры**: группировка комментариев по правилам, а также автоматическая кластеризация проблем через эмбеддинги (RuBERT-tiny2 + KMeans).
- **Визуализация**: графики динамики по дням, облако слов, распределение тем и тренд-анализ.
- **Экспорт**: выгрузка полного отчета в CSV и PDF (с графиками и таблицами).
- **Инсайты**: автоматическое сравнение с «нормой» по датасету и приоритизация комментариев (1–5).

## 🛠 Как запустить локально

**Шаг 1. Скачайте репозиторий**
Откройте командную строку (CMD или Terminal) и выполните:
`git clone https://github.com/AnaStarlet/Instagram_analysis.git`
`cd Instagram_analysis`

**Шаг 2. Создайте виртуальное окружение**
Это нужно, чтобы библиотеки не конфликтовали с системными.
Для Windows:
`python -m venv venv`
`venv\Scripts\activate`

Для Mac/Linux:
`python3 -m venv venv`
`source venv/bin/activate`

**Шаг 3. Установите зависимости**
`pip install -r requirements.txt`
*(Установка займет 3–5 минут, так как скачиваются ML-библиотеки)*

**Шаг 4. Запустите приложение**
`streamlit run app.py`

После этого в браузере автоматически откроется страница приложения (обычно `http://localhost:8501`). 

В левом меню нажмите **«Browse files»** и загрузите файл `real_comments_labeled.csv` (он лежит в корне проекта), чтобы начать анализ.

## 📁 Структура проекта
- `app.py` — главный файл веб-интерфейса (Streamlit).
- `analyzer.py` — логика определения тональности и тем.
- `embeddings_utils.py` — модуль для работы с эмбеддингами, кластеризации и трендов.
- `requirements.txt` — список всех необходимых Python-библиотек.
- `real_comments_labeled.csv` — подготовленный датасет с комментариями МВД-аккаунтов.
- `real_data/` — папка с исходными CSV-файлами.
