# 🕵 Insight Search: Анализ комментариев Instagram

Учебный проект (ГрГУ, группа «Искусственный интеллект»). 
Приложение анализирует комментарии к постам из Instagram: определяет тональность, группирует по темам, ищет инсайты и выгружает отчёты.

##  Функционал
- Загрузка данных (CSV, Excel, JSON).
- Поиск по ключевым словам (регистронезависимый).
- Определение тональности (RuBERT).
- Кластеризация проблем (RuBERT-tiny2 + KMeans).
- Построение графиков (динамика, облако слов, темы).
- Экспорт отчётов в CSV и PDF.
- Тренд-анализ и сравнение с нормой.
